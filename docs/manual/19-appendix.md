## 19.1 FAQ — សំណួរញឹកញាប់

### Q1: ខ្ញុំភ្លេច Password ធ្វើដូចម្តេច?
**A**: ទាក់ទង Admin ដើម្បី reset។ Admin អាចចូលទៅ `/admin/users` → Edit User → ដាក់ password ថ្មី។ ប្រសិនបើ Admin ក៏ភ្លេច → ប្រើ Artisan command៖
```bash
php artisan tinker
>>> User::where('email','admin@example.com')->first()->update(['password'=>Hash::make('newpass')]);
```

### Q2: ហេតុអ្វីខ្ញុំមិនឃើញ Booking របស់ Branch ផ្សេង?
**A**: ប្រព័ន្ធ scope ទិន្នន័យតាម Branch ដោយស្វ័យប្រវត្តិ (Multi-tenant)។ ដើម្បីមើល Branch ផ្សេង → ប្ដូរ Branch នៅលើ header (Branch Switcher) → ទំព័រនឹង reload ដោយស្វ័យប្រវត្តិ។

### Q3: Code ដូចជា `BK-000001`, `INV-000001` តើបង្កើតយ៉ាងម៉េច?
**A**: បង្កើតដោយ `CodeGeneratorService` តាមរយៈ Observer នៅពេល Create record។ មិនត្រូវកែដោយដៃ។ បើចង់ប្ដូរ Prefix → ប្រើ `Settings → Code Settings`។

### Q4: ខ្ញុំចង់ប្ដូរភាសាពី Khmer ទៅ English តើធ្វើដូចម្តេច?
**A**: ចុច language switcher (KM/EN) នៅ header → ប្រព័ន្ធនឹងផ្លាស់ប្ដូរភាសាដោយ AJAX (no page refresh) និងផ្លាស់ប្ដូរ DataTable header ភ្លាមៗ។

### Q5: Invoice ដែលខ្ញុំបង្កើតមិនបាន update status ទៅ "paid"
**A**: សូមពិនិត្យ៖
- Payment ត្រូវបាន create ហើយឬនៅ?
- Payment amount ≥ Invoice total ហើយឬនៅ?
- Receipt ត្រូវ auto-create — បើគ្មាន → ប្រហែលជា `PaymentObserver` មិនបាន register។

### Q6: ខ្ញុំចង់ delete record មួយតើធ្វើដូចម្តេច?
**A**: ចុច Delete icon → SweetAlert2 confirm dialog → Yes → AJAX delete → ទិន្នន័យលុបចេញ + Audit Log កត់ត្រា។

### Q7: Audit Logs មាន​ ​ ​ប្រវត្តិ​ ​ ​​ប៉ុន្មាន?
**A**: គ្មាន​ ​ ​​limit — system កត់ត្រាគ្រប់ការផ្លាស់ប្ដូរ។ ISO 9001 ណែនាំ retain យ៉ាងតិច ៣ ឆ្នាំ។

### Q8: ខ្ញុំទទួល "Permission denied" error
**A**: User Role របស់អ្នកមិនមាន permission។ ទាក់ទង Admin → `/admin/roles` → ផ្តល់ permission។

## 19.2 Troubleshooting

| បញ្ហា | ដំណោះស្រាយ |
|---|---|
| DataTable មិនបង្ហាញទិន្នន័យ | ពិនិត្យ browser console — បើ TypeError → ត្រូវ rebuild assets (`npm run build`) |
| Login ត្រឡប់ "Invalid credentials" | ពិនិត្យ caps lock; បើភ្លេច password → Q1 |
| Branch switcher បាត់ | User មិនត្រូវបាន assigned ទៅ Branch ច្រើន → Admin ត្រូវ assign |
| Locale switcher មិនដំណើរការ | Clear browser cache + `php artisan cache:clear` |
| Code (BK-, INV-) មិន generate | ពិនិត្យ Observer registration ក្នុង `AppServiceProvider` |
| Invoice total = 0 | InvoiceItem មិន trigger `Invoice::recalculate()` → ពិនិត្យ `InvoiceItemObserver` |
| Audit Log មិន record | Model អនុវត្ត `Auditable` trait ហើយឬនៅ? |
| Photo upload បរាជ័យ | ពិនិត្យ `storage/app/public` permissions + `php artisan storage:link` |

## 19.3 Glossary — សទ្ទានុក្រម

| ពាក្យ | និយមន័យ |
|---|---|
| **Branch** | សាខា Guest House (Multi-tenant scope) |
| **Stay** | រយៈពេលស្នាក់នៅ — បង្កើតពេល Check-in |
| **Booking** | កម្ម៉ង់បន្ទប់មុនពេលមកដល់ |
| **CAPA** | Corrective & Preventive Action — ISO 9001 §8.5.2/§8.5.3 |
| **RBAC** | Role-Based Access Control |
| **Observer** | Laravel mechanism that runs code on model events |
| **DataTable** | Yajra server-side data table |
| **i18n** | Internationalization (multi-language) |
| **ISO 9001** | International Quality Management System standard |
| **PDCA** | Plan-Do-Check-Act cycle |
| **Risk Score** | Likelihood × Impact (auto-computed) |
| **Audit Log** | Immutable change history record |
| **Idempotent** | Operation that produces same result if repeated |
| **Multi-tenant** | Single system serving multiple isolated tenants (branches) |
| **Auto-code** | Code generated by Observer (e.g. BK-000001) |
| **Housekeeping Task** | Cleaning/maintenance task auto-created after checkout |
| **Service Charge** | Extra service billed to a stay (laundry, food, etc.) |
| **Refund** | Money returned to guest |
| **Receipt** | Proof of payment auto-created by PaymentObserver |
| **Document Version** | Controlled SOP/Policy revision (ISO 9001 §4.2.3) |
